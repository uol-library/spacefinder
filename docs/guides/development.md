# Development

## Setting up

You need Ruby with Bundler, and Node.js 22 or later.

```sh
bundle install
npm install
```

## Scripts

| Command | What it does |
|---|---|
| `npm run serve` | builds the site and serves it at http://localhost:4000 |
| `npm run build` | builds the site into `_site` |
| `npm run test:routing` | runs the browser tests (see below) |
| `npm run docs` | regenerates the [API](../api/) pages from the code |
| `npm run docs:serve` | serves this documentation site locally |

The theme has only example data: the made-up `cafes` and `trees` datasets
in `assets/data`. The Leeds data, and the scripts that build it and keep
opening hours up to date, are in the
[spacefinder.leeds.ac.uk](https://github.com/uol-library/spacefinder.leeds.ac.uk)
repository.

## Tests

`npm run test:routing` builds the site twice, once for each
[routing](configuration.html#routing) setting, and serves each build the way
GitHub Pages does, sending `404.html` for paths that don't exist. Then it
drives headless Chrome through the same scenarios in both builds, using the
example datasets:

- selecting places, and going Back and Forward between them;
- search and filters;
- the information pages;
- direct visits to each dataset and to places;
- unknown places;
- hash links in history mode;
- the dataset's name in the interface;
- checking for JavaScript errors.

It needs Google Chrome. Add `-- --no-build` to reuse the last builds. The
builds are kept in `_tests/build`, which git ignores.

## Documentation

This site is in the `docs` folder. Its theme is
[Just the Docs](https://just-the-docs.com/), and the main site's Jekyll build
leaves the folder out.

- **Project and data model pages** started as the GitHub wiki. Edit them
  here.
- **API pages** are generated by `_scripts/docs.js`, using
  [jsdoc-to-markdown](https://github.com/jsdoc2md/jsdoc-to-markdown), from
  the JSDoc comments in `assets/js/modules`. Edit the comments, then run
  `npm run docs`. Each page starts with the comment at the top of its
  module, so give new modules one.
- **Guides** are written by hand.
